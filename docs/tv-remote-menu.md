# TV-guide och snabbmeny

TV-guiden visar hela kanalens kompakta logotyp i första kolumnen.
Kanalnamn och kanalnummer ingår redan i logotypen.
Den valda raden behåller sin TV-blå bakgrund och markeras med gul ram.

## Snabbmeny med fjärrkontroll

Snabbmenyn innehåller tre val i ordning:

1. **GUIDE**: öppnar programguiden.
2. **TXT**: öppnar Text-TV.
3. **INFO**: visar version och TV-inställningar.

Menyn visas en kort stund när kanalen väljs och döljs efter
fyra sekunder. Även den tillhörande statustexten döljs.
Tryck **vänster** eller **höger** för att visa menyn igen.
Fortsätt använda pilarna för att flytta mellan de tre valen.
Tryck **Enter/OK** för att öppna den valda funktionen.

När menyn är dold visar högerpilen först GUIDE.
Vänsterpilen visar INFO. Navigeringen går runt efter
första eller sista valet.

Tidigare genvägar fungerar: G för guide, T för Text-TV,
I för information och pilar upp/ned för kanalbyte.

## CRT i INFO

Öppna INFO och tryck Enter på **CRT - PÅ/AV**.
Värdet ändras direkt och sparas på enheten.
Den tidigare genvägen C öppnar nu INFO i stället för
att slå av eller på effekten utan att visa inställningen.

De här ändringarna kräver ingen server och använder
samma fjärrkontrollsmodell som Theves övriga menyer.

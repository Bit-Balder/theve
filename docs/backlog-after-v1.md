# Prioriterad backlog efter v1

## Nära efter v1

1. Lägg in ett första verkligt Internet Archive-program först efter separat
   rättighets- och familjegranskning.
2. Testa och dokumentera specifika fjärrkontrollkoder för familjens faktiska
   TV eller TV-box.
3. Förnya schemahorisonten automatiskt med en granskad pull request.
4. Utöka visuell kontroll med den vanligaste målskärmens upplösning.

## Senare

1. Utvärdera en enkel, familjevänlig katalogredigering.
2. Jämför Firebase endast om ett konkret behov av inloggning, synkronisering
   eller redigering uppstår; den statiska lösningen är fortsatt standard.
3. Lägg till fler Text-TV-sidor först när källvillkor och driftansvar är
   dokumenterade.
4. Utöka kanalutbudet endast om den gemensamma kanalidentiteten och
   rättighetsgrinden kan återanvändas utan specialkod.

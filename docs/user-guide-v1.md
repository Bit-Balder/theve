# Snabbguide för Theve v1

Theve öppnar direkt i programguiden. Allt går att använda med pilar, Enter,
siffror och Back; mus behövs inte.

## Börja titta

1. Flytta fokus i programguiden med pil upp eller ned.
2. Tryck Enter på den kanal du vill se.
3. Kanalens logotyp visas uppe till höger i fyra sekunder. Därefter återstår
   bara kanalnamnet, exempelvis `TV1`, utan bakgrund.

## Knappar under TV-bilden

- `GUIDE` öppnar programguiden igen.
- `TXT` öppnar Text-TV.
- `CRT PÅ` eller `CRT AV` växlar den diskreta bildrörseffekten.
- `INFO` visar appversion och revisionerna för publicerade data.

Samma funktioner finns på tangentbord och kompatibla fjärrkontroller:

| Funktion | Knapp |
| --- | --- |
| Byt kanal | Pil upp eller pil ned |
| Välj kanal direkt | 1–9 |
| Öppna guide | G eller Guide |
| Öppna Text-TV | T eller TXT |
| Teknisk information | I eller Info |
| Bildrörseffekt | C eller knappen CRT |
| Välj | Enter eller OK |
| Stäng överlägg | Escape, Backspace eller Back |

Klockan använder enhetens aktuella tid men visas alltid som svensk tid i
`Europe/Stockholm`.

## Text-TV

Text-TV startar på sida 100. Skriv tre siffror för att välja sida:

- 300: väderöversikt och lokalt väder;
- 301: välj län eller kommun;
- 302: sparade väderfavoriter;
- 400: tablå just nu;
- 500: Barnens sida.

Back går först bakåt inne i Text-TV och stänger sedan Text-TV.

## Barn

Barn visar ordinarie innehåll till 18.55, en godnattvinjett 18.55–19.00 och en
analog slutskylt 19.00–06.00.
